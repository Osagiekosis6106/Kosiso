# Footage Vault

Every archival photo, film clip and stock clip link for **Back When It Lasted**, grouped by video. Claude keeps this file up to date; the user never has to edit it.

**Say to Claude:**
- **"footage vault"** or **"send me my footage vault"** → Claude sends every link, grouped by video.
- **"footage vault for [video name]"** → only that video's links.
- **"add to footage vault"** + links, or a pasted `sourcing-log.csv` → Claude files them under the right video.
- **"footage vault: [video], beat [n] is used"** → Claude marks it ✅ used.
- **"copyright claim on [video]"** → Claude sends that video's links plus a ready-to-paste dispute text.

**Status:** 📋 planned (suggested in a script, not yet downloaded) · ✅ used (in the final video) · ❌ not used

**Columns:** Beat · Media (🎥 video / 🖼️ image) · What it shows · Source · Exact link · Licence · Status · Added
